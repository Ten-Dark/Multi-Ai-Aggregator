# Archived audits and forensic records

This directory contains historical assessments, incident reports and forensic evidence retained for traceability. These documents describe earlier repository states and may mention files, vulnerabilities, versions or architecture that have since changed.

They are **not the current implementation specification**. For current behavior, use the source tree, `docs/PROJECT_STRUCTURE.md`, the current architecture documents, ADRs, protocols and readiness baselines. Do not delete archived evidence as part of routine cleanup.
